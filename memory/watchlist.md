# 워치리스트

Stage 판정을 한 종목을 여기서 추적한다. 세션 시작 시 자동으로 읽힌다.
**행이 늘어나면 오래되고 무효화된 종목은 삭제한다.** (파일이 커지면 매 세션 비용이 늘어남)

|---|---|---|---|---|---|---|---|---|
| _(아직 없음)_ | | | | | | | | |

**상태 값:** 관찰 / 매수대기 / 보유중 / 손절됨 / 무효화 / 채점완료

**재점검일**이 지난 종목은 세션 시작 시 우선 확인한다.
