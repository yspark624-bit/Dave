# 계좌 구조

종목을 추천할 때는 반드시 **어느 계좌에 맞는지** 명시한다.
계좌마다 보유기간·세금·리스크 허용도가 다르므로, 같은 종목이라도 적합한 계좌가 다르다.

| 계좌 | 구분 | 보유기간 | 성격 | 리스크 |
|---|---|---|---|---|
| Webull | 단기 스윙 | 수일 ~ 수주 | 과세 계좌. 회전율 높음 | 높음 |
| Roth IRA ① (Vanguard) | 중기 | 수개월 ~ 1~2년 | 세후 납입, 인출 시 비과세 | 중간 |
| Roth IRA ② (브로커 미확인) | 중기 | 수개월 ~ 1~2년 | 세후 납입, 인출 시 비과세 | 중간 |
| 401k ① (Principal) | 장기 | 수년 ~ 은퇴 | 세전 납입, 상품 선택 제한적일 수 있음 | 낮음 |
| 401k ② (Ascensus) | 장기 | 수년 ~ 은퇴 | 세전 납입, 상품 선택 제한적일 수 있음 | 낮음 |

## 계좌 배정 원칙

- **Webull (단기)** — Stage 2 초기 돌파, VCP 완성 직후 진입. 손절을 타이트하게 잡고
  추세가 깨지면 빠르게 정리한다. 변동성 큰 개별 종목 허용.
- **Roth IRA (중기)** — Stage 2가 이미 확인되고 기관 수급이 붙은 주도주 중심.
  비과세 계좌이므로 회전보다 **큰 폭의 상승을 온전히 먹는 것**이 유리하다.
  단기 트레이딩용으로 쓰지 않는다.
- **401k (장기)** — 개별 종목보다 인덱스·섹터 중심. 401k는 상품 목록이 정해져 있어
  개별 주식 매수가 불가능한 경우가 많으므로, 추천 전에 **선택 가능한 상품 목록을
  확인**해야 한다.

## 확인 필요 (미입력 항목)

아래는 아직 알지 못하는 정보다. 채워 넣으면 분석 정확도가 올라간다.

- [ ] Roth IRA ②의 브로커리지 이름
- [ ] 각 계좌의 대략적 비중 (전체 자산 대비 %)
- [ ] 401k 2개에서 선택 가능한 펀드/상품 목록
- [ ] 현재 보유 종목 및 평단가
- [ ] 연간 납입 여력 (Roth IRA 한도 소진 여부)
