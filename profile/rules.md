# 분석 기준

## 1. Stage 분석 (Stan Weinstein → Minervini)

| Stage | 상태 | 대응 |
|---|---|---|
| Stage 1 | 바닥 다지기, 횡보 | 관망. 매수 안 함 |
| **Stage 2** | **상승 추세** | **매수·보유 구간. 여기만 후보** |
| Stage 3 | 천장 다지기, 변동성 확대 | 신규 매수 금지. 보유분 축소 검토 |
| Stage 4 | 하락 추세 | 매수 금지. 보유분 정리 |

Stage 판정 근거를 항상 기록에 남긴다. "Stage 2로 보인다"가 아니라
아래 추세 템플릿 충족 개수로 판정한다.

## 2. 미너비니 추세 템플릿 (8개 항목)

Stage 2 판정의 객관적 기준. 충족 개수를 세어 기록한다.

1. 현재가가 150일선과 200일선 **위**에 있다
2. 150일선이 200일선 **위**에 있다
3. 200일선이 최소 1개월 이상 **상승** 중이다 (4~5개월이면 더 좋다)
4. 50일선이 150일선과 200일선 **위**에 있다
5. 현재가가 50일선 **위**에 있다
6. 현재가가 52주 **저가 대비 +30% 이상**이다
7. 현재가가 52주 **고가의 25% 이내**에 있다 (고가에 가까울수록 좋다)
8. **RS(상대강도) 등급 70 이상** (선호: 80~90 이상)

판정: 8개 모두 충족 = 명확한 Stage 2 / 6~7개 = 조건부 / 5개 이하 = Stage 2 아님

## 3. CANSLIM (오닐) — 펀더멘털

| 항목 | 기준 |
|---|---|
| **C** Current earnings | 최근 분기 EPS 전년 동기 대비 **+25% 이상** |
| **A** Annual earnings | 연간 EPS 3년 연속 성장, **ROE 17% 이상** |
| **N** New | 신제품·신경영진·신고가 등 새로운 촉매 |
| **S** Supply/Demand | 유통 주식수 적을수록 유리, 돌파 시 **거래량 급증** |
| **L** Leader | 업종 내 선도주인가. 후발주는 피한다 |
| **I** Institutional | 기관 보유 **증가** 추세인가 |
| **M** Market direction | **가장 중요.** 시장이 조정/하락이면 신규 진입 보류 |

M(시장 방향)을 항상 먼저 본다. 시장이 나쁘면 아무리 좋은 종목도 보류한다.

## 4. 리스크 관리 (초기 기본값 — 본인 확인 필요)

아래는 미너비니의 일반적 기준을 초기값으로 넣은 것이다.
**사용자 본인의 실제 원칙으로 교체해야 한다.**

- 동시 보유 종목: 4~8개 (분산 과다는 수익을 희석시킨다)
- 단일 종목 비중 상한: 미정
- 시장이 Stage 4일 때: 현금 비중 확대

## 5. 분석 시 지켜야 할 것

- Stage 2가 **아닌** 종목은 추천하지 않는다. 물어본 종목이 Stage 3/4면 그 사실을 말한다.
- 추세 템플릿 충족 개수를 **숫자로** 제시한다.
- 진입가·손절가·목표가를 함께 제시한다. 손절가 없는 추천은 하지 않는다.
- 데이터 조회 시점을 명시한다. 장중/장후 여부로 값이 달라진다.
- 예측을 단정하지 않는다. 조건과 무효화 지점(손절)을 함께 말한다.
