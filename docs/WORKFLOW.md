# 매일 루틴 — 토큰 0원으로 혼자 할 수 있는 일

## 최초 1회 설정 (본인 PC에서)

```bash
git clone <이 저장소> Dave && cd Dave
# 설치할 것 없음. 파이썬 3.8 이상이면 표준 라이브러리만으로 동작합니다.
python3 -V
```

`memory/watchlist.txt` 를 열어 감시할 종목을 적습니다. (30종목 이내 권장)

## 매일 장 마감 후 (약 2분, 토큰 0)

```bash
bash scripts/run_daily.sh
```

이 한 줄이 순서대로 실행합니다.

1. `fetch_bars.py` — Yahoo Finance에서 2년치 일봉 무료 수집 → `data/bars/`
2. `stage2_screen.py` — Minervini 8단계 트렌드 템플릿 + O'Neil RS 백분위 로컬 계산
3. `make_report.py` — 한글 HTML 리포트 생성 → `out/report.html`

결과는 터미널에 이런 표로 나옵니다.

```
시장 국면  2026-09-12 | SPY 612.40  200MA대비 +7.2%  기울기 +1.1%/월 -> 상승(매수 가능)
종목   국면      TT   RS     주가   50MA%   고점%    3M%   신호  계좌
NVDA  Stage 2  8/8   96   184.20  +3.1%   -2.4%  +22.1%  VCP  Webull(스윙)
AVGO  Stage 2  7/8   88   342.10  +6.8%   -7.1%  +14.0%        RothIRA(중기)
```

PDF가 필요하면 `out/report.html` 을 브라우저로 열고 **Ctrl+P → PDF로 저장**.

## AI를 부를 때 (토큰 아끼는 호출법)

터미널 출력 표를 **그대로 복사해서** 붙여넣고 질문합니다.

> ```
> (표 붙여넣기)
> ```
> Stage 2 중에서 Webull 스윙 계좌로 지금 진입할 종목 1개만 골라주고,
> 손절가와 1차 목표가를 제시해줘.

이렇게 하면 1회 질문이 **약 500토큰**입니다. (MCP로 시세를 받으면 같은 질문이 75만 토큰)

### 하지 말아야 할 호출

- ❌ "NVDA, AVGO, AMD ... 20종목 주가 데이터 받아서 Stage 2인지 분석해줘"
- ❌ "이 폴더 전체 파일을 PDF로 요약해줘" (폴더가 커지면 매번 전량 재과금)
- ❌ 5분마다 자동 반복 감시

### 해야 할 호출

- ✅ 스크리닝 결과 표를 붙여넣고 "이 중 무엇을 살까"
- ✅ 후보를 3종목 이내로 좁힌 뒤 "이 3개의 최근 실적과 가이던스를 비교해줘"
- ✅ "지난달 매매 일지(`memory/journal/`)를 보고 내 실수 패턴을 짚어줘"

## 주 1회 (일요일)

1. `memory/journal/YYYY-MM-DD.md` 에 이번 주 매매 기록을 남깁니다.
2. AI에게 일지를 요약시켜 `memory/lessons.md` 에 교훈을 누적합니다. (폐쇄형 학습 루프)
3. 감시 리스트를 갱신합니다 — Stage 4로 떨어진 종목은 제거.
